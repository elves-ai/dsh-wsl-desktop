# 桌面 UI 设计规范

适用范围：DSH WSL Desktop 设置页、桌宠右键菜单、提醒气泡、对话气泡、确认卡片与输入框。版本：1.1。

## 1. 设计方向

像工具，不像宣传页。设置页使用安静的石墨灰，桌宠菜单使用接近系统浮层的中性浅色；两者共享字号、间距、圆角、图标和状态规则，不强行把透明桌宠窗口染成深色。

- 层级由位置、字重、留白和分隔线建立，不靠大卡片、渐变、发光和多种强调色。
- 不使用编号式导航、英文眉题、装饰性徽标、emoji 图标或重复页面标题。
- 不增加功能、改变默认值或自动执行操作。原生选择器、确认流程、权限、异步状态和错误信息保持原样。

## 2. 设计变量

变量集中在 [ui-tokens.css](../src/ui-tokens.css)，设置页与菜单都导入。不要在组件内另造一套近似颜色。

| 语义 | 设置页 / 深色 | 菜单 / 浅色 |
| --- | --- | --- |
| 页面背景 | #202124 | #ffffff |
| 侧栏 / 次级背景 | #191a1d | #f5f5f6 |
| 输入框背景 | #191a1d | #f5f5f6 |
| 主文字 | #eeeeef | #26272b |
| 次级文字 | #a5a6ad | #62646c |
| 辅助文字 | #92939c | #6c6e77 |
| 分隔线 | #35363b | #e4e4e7 |
| 控件边框 | #505158 | #c7c8cd |
| 悬停 | #2b2c31 | #f0f0f2 |

强调色仅用于主按钮、开关、焦点与必要链接。错误除颜色外必须有文字说明；禁用不等于未开启。

## 3. 字体与尺寸

- 系统字体：Segoe UI Variable → Segoe UI → Microsoft YaHei UI → system-ui。中文不加字间距。
- 页标题 24px / 32px，600；分组标题、设置项名称 13px / 20px，600。
- 导航与操作 13px / 20px；说明 12px / 20px；菜单正文 12px / 18px；辅助注记最小 11px / 16px。
- 路径、日志使用 Cascadia Code / Consolas 等宽字体，12px，允许横向滚动或换行，不能撑开页面。
- 间距基于 4px：4 / 8 / 12 / 16 / 24 / 32。单像素只用于边框。
- 控件圆角 6px，浮层圆角 8px；开关与滑块可使用圆形。无圆角套圆角的大卡片。
- 图标统一 16px、24×24 viewBox、1.5px 线条、圆端点。无彩色底板。图标必须伴随可读标签；纯图标按钮必须有 aria-label。

## 4. 设置页布局

- 桌面侧栏 184px，导航行至少 36px。侧栏固定在可视区域，内容独立滚动；窗口变窄时改为顶部可横向滚动的导航，不能压成两行碎字。
- 内容左右留白 32px，正文最大宽度 760px。标题至正文 24px，分组间距 24px。窄屏缩至 20px。
- 导航去掉 01—06，改用同一线性图标；选中行使用低对比填色与 2px 左侧指示条，并保留 aria-current。
- 每个设置行左侧为名称和简短说明，右侧开关固定宽度，不随长文案挤压。相邻项用细线分组。
- 路径输入和“选择…”组成一行；状态提示放在下方，保存操作独立。不把只读路径伪装为可编辑字段。
- 长篇策略说明收进有明确标题的原生 details，默认折叠；错误和实时状态不可折叠隐藏。授权、下载、初始化前的必要告知仍须直接可见。
- 本地语音继续归属桌面宠物：常用偏好优先，以“一键安装”统一准备环境、依赖、原生库、模型和检测保存，不要求选择目录。安装前直接说明联网与磁盘占用，过程显示进度、取消及失败重试；打开页面不安装，加载模型仍须显式操作。
- 状态列表采用左标签右值，不做六个状态徽章或仪表盘。来源与素材限制保留。
- “人格与长期记忆”归属桌面宠物，先显示默认关闭开关、模型发送告知与真实接入状态；本地开关打开不等于当前会话已接入。人格使用默认折叠的名字/语气编辑；记忆提供每页 10 条的搜索、来源、纠正与忘记，忘记全部包含未显示条目并明确确认，不删 DSH 历史。不可用时禁写并保留重新读取与草稿；不展示 token、Top-K、数据库路径等内部调参项。

## 5. 控件

- 普通按钮高至少 34px，水平内边距 12px；主按钮浅强调底深文字，次按钮中性底细边框。每组最多一个主要操作。
- 输入框高至少 36px；有边框、清楚的只读 / 禁用状态。范围控件使用强调色，当前数值右对齐。
- 开关轨道 36×20px，滑块 12px；开启靠右且填强调色，关闭靠左且为中性色。保留原生 checkbox 语义和键盘操作。
- Hover 只改变背景 / 边框，不平移、不缩放。Active 比 hover 深一阶。所有交互元素有 2px focus-visible 外框，不能以取消 outline 掩盖焦点。
- 过渡 120ms，仅颜色类属性；尊重 prefers-reduced-motion。不新增入场动画。

## 6. 桌宠右键菜单

- 宽 196px，内边距 4px，按钮行高 26px。浅色不透明背景、1px 边框、轻阴影，不做玻璃渐变。
- 菜单必须适配现有 360×320 透明窗口，不扩大原生窗口、不移动角色。高度受可见边界约束，空间不足可滚动，所有操作始终可达。
- 三组：对话（说句话、重看、历史、打开 DSH）；偏好（自动朗读、动作、置顶）；管理（设置、隐藏）。用分隔线，不堆叠分组标题。
- 操作图标、文字、右侧状态各自对齐；自动朗读和置顶用 aria-checked 驱动的“开 / 关”文字标记，不反复变换整行文案长度。不把“隐藏宠物”标红，它不是破坏性操作。
- “选择动作”使用二级菜单，悬停或点击展开，分组展示全部动作并支持键盘选择。左右择侧，在现有透明窗口内夹取；空间过窄时允许覆盖主菜单并提供返回。关闭按钮保留。Esc、外部点击、再次右键、操作后收起行为不变。
- 不添加不存在的快捷键提示，不改朗读与置顶的异步读回语义。
- 菜单焦点框采用内描边，避免被滚动容器裁切。保存失败在右侧显示明确文字，并提供可访问描述；未知状态与关闭状态分开显示。

## 7. 桌宠气泡、确认与输入展示规范

### 7.1 共用视觉与结构

- 沿用菜单的浅色变量：白底、1px 中性边框、8px 浮层圆角、轻阴影；去掉蓝色渐变、发光和多层装饰边框。不改变透明窗口大小。
- 正文 12px / 20px；确认标题 13px / 20px、600；来源、说明与辅助操作 11px / 16px，不能为塞下更多文字而缩到 9px。
- 内容内边距 8–12px，间距 4 / 8px。关闭按钮至少 24px，确认按钮至少 30px，输入与发送按钮至少 36px；焦点轮廓 2px，选中状态同时用原生选中控件和边框表达，不只靠颜色。
- 卡片分为标题、正文、操作区；正文占剩余空间并独立滚动，标题、关闭与确认按钮不随长正文滚走。错误和提交状态放在操作区上方，不能藏到长文末尾。

### 7.2 各类内容的显示规则

| 类型 | 默认展示 | 长文处理 | 完整内容入口 |
| --- | --- | --- | --- |
| 完成 / 失败 / 待答提醒 | 标题 1 行、摘要最多 3 行；最大宽 324px、高 110px | 明确为摘要，不用摘要替代授权或问题正文 | 点击气泡打开对应 DSH 会话 |
| 普通回复、思考、连接错误 | 保留换行，正文最多 3 行；短文自然高度，收起态最大 152px | 根据实际渲染溢出显示“展开全文”，不按字数或消息类型猜测；展开后正文滚动、可选中复制，最大 256px | 同一气泡展开 / 收起，不丢失原文 |
| 问题、计划、权限确认 | 最大宽 348px、高 280px；短标题与来源分行 | 问题、选项说明、完整计划和权限参数不能截断、行数省略或静默折叠；整个正文区滚动 | 卡片内阅读完整内容，另保留“在 DSH 打开” |
| 临时输入 | 在角色脚下独立显示，宽最多 324px | 输入区 36–72px，多行增长到上限后框内滚动；整体最多 128px，提示和按钮仍可达 | 当前草稿保留，不因关闭、阅读回复而清空 |

- 中文正常换行，连续英文、URL、路径用 anywhere 断行，不撑出横向边界；用户文本保持 textContent 等安全文本输出，不因美化引入 HTML 执行。
- 权限原始参数用等宽字体，完整显示；计划保留原始换行和所有文字。只能省略来源行的视觉长度（保留完整 title 提示），不能省略影响选择或授权判断的正文。
- 只有正文实际溢出才出现“展开全文”；展开后提供键盘可聚焦滚动区。阅读展开正文、悬停或选择文字时沿用暂停自动收起规则。
- 展开不额外开原生窗口、不挤压输入、不缩放角色。优先放在角色旁的空白处；空间不足时允许在既有窗口内覆盖角色，不把正文压成只剩一行的狭条。面板始终位于可见工作区内，左右屏边和短高度同样适用。

### 7.3 确认选择与输入

- 原生 radio / checkbox 保留；整行标签可点，选项标题与说明分层，可完整换行。明确标出单选 / 可多选，不默认选中推荐项，不通过颜色或排序暗示已同意。
- 问题组去掉套框；问题、选项、补充回答按阅读顺序排布。自由回答提供可见标签而非只靠 placeholder，文本域默认 2 行，长内容框内滚动。
- 每组最多一个主要操作。问题显式提交；权限仅“允许一次 / 拒绝”；“在 DSH 打开”为次要操作。窄空间按钮换行，不能变成一个字一行或被横向裁切。
- 计划确认保留原始选项与回传值；有反馈时不得批准，继续规划必须显式选择。提交中防重、断线禁用、结果未知、请求撤回、IME 保护、关闭不取消等既有语义不变。
- 临时输入与气泡是相邻的独立区域，点击输入、发送、关闭或气泡操作都不能被误判为“点到外部”。Enter 发送、Shift+Enter 换行；中文候选确认不发送。关闭保留草稿，不自动提交。

### 7.4 可复现预览

使用 [统一展示预览](../tests/fixtures/pet-display-preview.html) 检查短 / 长回复、错误、输入、单选、多选、计划、权限以及失败状态；预览只模拟数据，不连接 DSH、不执行命令、不发送真实授权。

验收覆盖：360×320 标准窗口、左右 112.5px 屏边留白、240px 短窗口，超长中文 / 无空格路径、多段文案、选中 / 焦点 / 禁用 / 错误状态。检查标题、操作区可见，正文能滚动到底且不出现整页横向溢出。

## 8. 验收

- 设置六个分类、语音区域、错误 / 禁用 / 焦点状态均采用同一规范；没有残留编号导航。
- 在 960×720 与 360px 窄屏查看，标题、路径、操作按钮均不导致横向溢出。
- 在 360×320 检查菜单：顶部和底部均不裁切；置顶 / 自动朗读状态可辨认，动作选择可用。
- 运行前端测试与生产构建；浏览器只使用无原生连接预览，不发真实模型请求、不切换用户偏好。Windows WebView2 原生选择器、焦点与透明窗口效果需单独实机验收。
