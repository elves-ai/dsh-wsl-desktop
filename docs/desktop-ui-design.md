# 桌面 UI 设计规范

适用范围：DSH WSL Desktop 设置页、桌宠右键菜单。版本：1.0。

## 1. 设计方向

像工具，不像宣传页。设置页使用安静的石墨灰，桌宠菜单使用接近系统浮层的中性浅色；两者共享字号、间距、圆角、图标和状态规则，不强行把透明桌宠窗口染成深色。

- 层级由位置、字重、留白和分隔线建立，不靠大卡片、渐变、发光和多种强调色。
- 不使用编号式导航、英文眉题、装饰性徽标、emoji 图标或重复页面标题。
- 不增加功能、改变默认值或自动执行操作。原生选择器、确认流程、权限、异步状态和错误信息保持原样。

## 2. 设计变量

变量集中在 [ui-tokens.css](../src/ui-tokens.css)，设置页与菜单都导入。不要在组件内另造一套近似颜色。

| --- | --- | --- |
| 页面背景 | #202124 | #ffffff |
| 侧栏 / 次级背景 | #191a1d | #f5f5f6 |
| 输入框背景 | #191a1d | #f5f5f6 |
| 主文字 | #eeeeef | #26272b |
| 次级文字 | #a5a6ad | #62646c |
| 辅助文字 | #92939c | #6c6e77 |

| 控件边框 | #505158 | #c7c8cd |

## 3. 字体与尺寸

- 系统字体：Segoe UI Variable → Segoe UI → Microsoft YaHei UI → system-ui。中文不加字间距。
- 页标题 24px / 32px，600；分组标题、设置项名称 13px / 20px，600。
- 导航与操作 13px / 20px；说明 12px / 20px；菜单正文 12px / 18px；辅助注记最小 11px / 16px。
- 路径、日志使用 Cascadia Code / Consolas 等宽字体，12px，允许横向滚动或换行，不能撑开页面。
- 间距基于 4px：4 / 8 / 12 / 16 / 24 / 32。单像素只用于边框。
- 控件圆角 6px，浮层圆角 8px；开关与滑块可使用圆形。无圆角套圆角的大卡片。
- 图标统一 16px、24×24 viewBox、1.5px 线条、圆端点。无彩色底板。图标必须伴随可读标签；纯图标按钮必须有 aria-label。

## 4. 设置页布局

- 桌面侧栏 184px，导航行至少 36px。侧栏固定在可视区域，内容独立滚动；窗口变窄时改为顶部可横向滚动的导航，不能压成两行碎字。
- 内容左右留白 32px，正文最大宽度 760px。标题至正文 24px，分组间距 24px。窄屏缩至 20px。
- 导航去掉 01—06，改用同一线性图标；选中行使用低对比填色与 2px 左侧指示条，并保留 aria-current。
- 每个设置行左侧为名称和简短说明，右侧开关固定宽度，不随长文案挤压。相邻项用细线分组。
- 路径输入和“选择…”组成一行；状态提示放在下方，保存操作独立。不把只读路径伪装为可编辑字段。
- 长篇策略说明收进有明确标题的原生 details，默认折叠；错误和实时状态不可折叠隐藏。授权、下载、初始化前的必要告知仍须直接可见。
- 本地语音继续归属桌面宠物：常用偏好优先，技术配置可折叠，加载模型、下载和初始化必须显式操作。
- 状态列表采用左标签右值，不做六个状态徽章或仪表盘。来源与素材限制保留。

## 5. 控件

- 普通按钮高至少 34px，水平内边距 12px；主按钮浅强调底深文字，次按钮中性底细边框。每组最多一个主要操作。
- 输入框高至少 36px；有边框、清楚的只读 / 禁用状态。范围控件使用强调色，当前数值右对齐。
- 开关轨道 36×20px，滑块 12px；开启靠右且填强调色，关闭靠左且为中性色。保留原生 checkbox 语义和键盘操作。
- Hover 只改变背景 / 边框，不平移、不缩放。Active 比 hover 深一阶。所有交互元素有 2px focus-visible 外框，不能以取消 outline 掩盖焦点。
- 过渡 120ms，仅颜色类属性；尊重 prefers-reduced-motion。不新增入场动画。

## 6. 桌宠右键菜单

- 宽 196px，内边距 4px，按钮行高 26px。浅色不透明背景、1px 边框、轻阴影，不做玻璃渐变。
- 菜单必须适配现有 360×320 透明窗口，不扩大原生窗口、不移动角色。高度受可见边界约束，空间不足可滚动，所有操作始终可达。
- 三组：对话（说句话、重看、历史、打开 DSH）；偏好（自动朗读、动作、置顶）；管理（设置、隐藏）。用分隔线，不堆叠分组标题。
- 操作图标、文字、右侧状态各自对齐；自动朗读和置顶用 aria-checked 驱动的状态标记，不反复变换整行文案长度。不把“隐藏宠物”标红，它不是破坏性操作。
- 动作仍使用原生 select，避免在透明窗口再开自绘子菜单。关闭按钮保留。Esc、外部点击、再次右键、操作后收起行为不变。
- 不添加不存在的快捷键提示，不改朗读与置顶的异步读回语义。
- 菜单焦点框采用内描边，避免被滚动容器裁切。保存失败在右侧显示明确文字，并提供可访问描述；未知状态与关闭状态分开显示。

## 7. 验收

- 设置六个分类、语音区域、错误 / 禁用 / 焦点状态均采用同一规范；没有残留编号导航。
- 在 960×720 与 360px 窄屏查看，标题、路径、操作按钮均不导致横向溢出。
- 在 360×320 检查菜单：顶部和底部均不裁切；置顶 / 自动朗读状态可辨认，动作选择可用。
- 运行前端测试与生产构建；浏览器只使用无原生连接预览，不发真实模型请求、不切换用户偏好。Windows WebView2 原生选择器、焦点与透明窗口效果需单独实机验收。
